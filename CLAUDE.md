# Portfolio Project Knowledge

## Architecture
This is a React single-page portfolio. `App.tsx` maps flat URL paths to section IDs, and `ContentArea.tsx` lazy-loads the corresponding project page. Project pages use the shared `PageGrid`, typography, spacing, sticky-title, and project-navigation modules.

## Project Structure
- `src/pages/`: project pages, including the coded OGEN diagrams in `Ogen.tsx`, Signal 50 in `Signal50.tsx`, and Nabat in `Nabat.tsx`
- `src/pages/ogen/videoCrop.ts`: manual knobs for OGEN screen + prototype video crop % and corner radius
- `src/components/`: reusable layout, navigation, and home-page components
- `src/components/IntroToggle.tsx`: shared Brief / Concept / Tools click-to-reveal buttons for project intros
- `src/components/SneakPeekImage.tsx`: home cube-hover floating sneak-peek image (safe zones + fade)
- `src/lib/routes.ts`: valid flat routes and path/section conversion
- `src/lib/sneakPeekPool.ts`: curated per-project sneak-peek image URLs for home hover
- `src/lib/`: shared typography, spacing, layout, and media helpers
- `evidence/`: Playwright reviewer walkthrough specifications
- `playwright.config.ts`: Playwright evidence configuration
- `public/cursors/`: site brand mouse cursors (`default.png`, `pointer.png`, `grab.png`, `grabbing.png`)

## Test Patterns
- Playwright reviewer evidence is **not required** for this portfolio (see `.cursor/rules/no-playwright-evidence.mdc`). Do not run or upload walkthroughs unless the user explicitly asks.
- When evidence *is* requested: run with `npx playwright test`; specs live in `evidence/` and must declare `test.use({ video: "on" })`; use deliberate 1000–1500 ms pauses between walkthrough steps.
- OGEN evidence verifies section order (Research → Challenges → Persona → Architecture → Design), the persona portrait and navy card, full-width IA and User Flow on cols 3–8 (4–4–2) under a sticky Architecture title, no horizontal overflow, hierarchy sizing, `6px` node corner radius, Design semi-titles (Low/High Fidelity, Screens, Design System), the High Fidelity and Screens drag carousels, and Design System individual curated media (color palette PNG, typography PNGs, 17 icons + 7 status badges, equal-height buttons/inputs/filters, Anchor List popup pair, stacked report popups — no composite screenshot, no placeholders).
- Home cube evidence verifies all five `New Cubes` assets via `cloudinaryUrl` (BLUE rest / PINK hover), labels (Lumina Forest, OGEN, Pack Up, Nabat, Signal), and click routes (`/lumina`, `/ogen`, `/packup`, `/nabat`, `/signal50`).
- Signal 50 evidence verifies intro tags (Brand Identity / On-Screen Graphics), Brief/Concept/Tools toggles, overview showreel on cols 2–7 with controls, and section order (Brand Strategy → Visual Language → Deliverables) including Brand Values (four columns), Visual Language inspirations galleries (20 + 10), Color Palette & Typography with MuchiWaze-style hover bars on page cols 3–5 beside `signal50_typography_rbguqy` on cols 6–7, five muted looping decade shortvids (70–10), and body copy, logo process, Grid System three vertical grid inspirations left of the grid video (cols 3 | 4–7), and the five Deliverables titles each with a video (Commercial Promo includes the AiFrame source-frames drag carousel above the clip and a hover-swap stage mockup below).
