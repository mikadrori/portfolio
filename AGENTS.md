# Portfolio Agent Guide

## Stack
- React 19 and TypeScript
- Vite 6
- Tailwind CSS 4
- Motion for section transitions
- Playwright for recorded UI evidence

## Anti-patterns
- Do not remove existing project routes when reassigning a home-page cube.
- Do not embed reference screenshots when the requested result is a coded interface.
- Do not add diagram overflow that requires horizontal scrolling.
- Do not bypass shared typography, spacing, grid, or project-navigation components.

Read `CLAUDE.md` for architecture, routes, selectors, and test conventions.
